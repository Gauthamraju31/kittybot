Flashing Firmware to Waveshare Board

  1. Connect Hardware: Plug your Waveshare ESP32-S3 1.28" board into your computer using a USB-C data cable.
  2. Open in PlatformIO / VSCode: Open the root project folder kittybot in VSCode with PlatformIO installed.
  3. Build & Flash: Run the build command in terminal: 
    pio run -t upload
  4. Web Serial Controls: Click the 🔌 Connect USB Serial button above to connect your browser directly to the ESP32-S3 over USB at 115200 baud!
